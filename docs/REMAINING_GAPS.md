# NCAA remaining gaps and acceptance checks

Updated 2026-10-14. Target: NCAA Football 10 PSP US, ULUS10440, AOT C++/WebAssembly. Default guest RAM is 64 MiB, with a 56 MiB user partition. This checklist tracks evidence, not a promise of full compatibility.

Latest rendering evidence: RGB565 destination-alpha blending and presentation sampler ownership now have passing regressions. Native captures explicitly request and verify RGBA8. Earlier GLES replay images used RGBA4444 and their color-error metrics are superseded: corrected direct software-reference RGB MAE is 0.5737 for SDSU and 1.0227 for Georgia Tech–Georgia. RGBA8 presentation matches direct guest RGB565 readback exactly in both scenes. This is a measurement correction, not a demonstrated scene improvement from the latest source fixes. Latest package `build/static-ncaa10-presentation-alpha` passes web/package/native checks. Fresh browser gameplay/FPS remains pending Chrome app access. GPU post-blend dithering/packing, alpha/stencil precision and complete hardware agreement remain open. See [reference evidence](PPSSPP_REFERENCE.md).
